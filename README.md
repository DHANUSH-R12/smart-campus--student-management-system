Smart campus is a web-based Student Management system developed using PHP,MYSQL,CSS and JavaScript. It provides login and registration ,student records management, attendance tracking ,marks management ,and report generation through a responsive and user-friendly dashboard.
FEATURES
- SmartCampus branding with responsive professional interface
- Administrator registration and login with hashed passwords
- Dashboard overview and recent student records
- Add, edit, search and delete student profiles
- Daily attendance register
- Subject-wise internal and semester marks
- Student summary report and Print / Save as PDF
